# 단어의 신 GRE - 사용자 가이드

## 앱 소개

GRE 시험 대비를 위한 1,500개 필수 어휘 학습 앱입니다. 과학적으로 검증된 간격 반복(Spaced Repetition) 알고리즘을 활용하여 효율적으로 단어를 암기할 수 있습니다.

---

## 주요 기능

### 1. 플래시카드 학습 (`/study`)

매일 설정한 목표만큼 단어를 학습합니다.

**학습 흐름:**

1. **첫 학습**: 카드를 탭하여 뜻 확인 → "다음 단어" 버튼으로 진행
2. **복습 퀴즈**: 첫 학습 완료 후 → "몰라요/알아요" 선택으로 테스트
3. **틀린 단어 복습**: "몰라요" 선택한 단어만 반복 → 모두 맞출 때까지

**기능:**

- 자동 발음: 카드가 나타날 때 자동으로 발음 재생 (on/off 설정 가능)
- 수동 발음: 카드 뒷면의 스피커 버튼으로 발음 재생
- 진행률 표시: 상단에 현재 진행 상황 표시 (예: 5/25)

---

### 2. 퀴즈 모드 (`/quiz`)

학습한 단어를 테스트하는 두 가지 퀴즈 유형을 제공합니다.

**빈칸 채우기:**

- 영어 예문에서 빈칸에 들어갈 단어 선택
- 한글 해석 제공
- 4지선다

**객관식:**

- 한글 뜻을 보고 영어 단어 선택
- 4지선다

**조건:**

- 최소 4개 이상의 단어를 학습해야 퀴즈 시작 가능
- 학습한 모든 단어가 출제됨

---

### 3. 단어장 (`/vocabulary`)

전체 1,500개 단어를 검색하고 관리합니다.

**필터 옵션:**

- 전체: 모든 단어
- 학습 중: 현재 학습 진행 중인 단어
- 완료: 마스터한 단어
- 북마크: 즐겨찾기한 단어

**기능:**

- 단어/뜻 검색
- 북마크 추가/제거
- 단어별 정답률 확인
- 상세 정보 (예문, 해석) 확인

---

### 4. 통계 (`/stats`)

학습 진행 상황을 한눈에 확인합니다.

**표시 정보:**

- 전체 진도율 (마스터한 단어 / 1,500개)
- 연속 학습일 (스트릭)
- D-day (시험까지 남은 일수)
- 상태별 단어 수 (새 단어 / 학습 중 / 완료)
- 난이도별 진도 (Level 1, 2, 3)

---

### 5. 설정 (`/mypage`)

**변경 가능한 설정:**

- 목표 시험일: D-day 계산 기준
- 하루 학습량: 10~50개 (기본 25개)
- 자동 발음: on/off

## 간격 반복(SR) 복습 시스템

단어를 효율적으로 장기 기억으로 전환하기 위해 과학적 간격 반복 시스템을 사용합니다.

### 복습 간격

```
1일 → 2일 → 4일 → 7일 → 14일 → 30일
```

### 작동 방식

- **정답**: 다음 간격으로 이동 (예: 1일 → 2일)
- **오답**: 1일차로 리셋
- **마스터 조건**: 3회 이상 정답 + 7일 이상 간격 도달

### SR 복습하기 (홈 화면)

학습한 단어는 간격 반복 알고리즘에 따라 자동으로 복습 일정이 잡힙니다.

**복습 알림:**

- 홈 화면에 "복습할 단어가 있어요 - N개 대기 중" 표시
- **"복습하기" 버튼**을 눌러 복습 전용 모드 진입

**복습 전용 모드 특징:**

- 새 단어 없이 **복습 대상 단어만** 학습
- 카드를 넘기면 해당 단어의 복습 간격이 자동 업데이트
- "SR 복습" 배지로 일반 학습과 구분
- 복습 완료 시 다음 복습일이 자동 설정됨

**학습 모드 비교:**

| 구분      | 오늘의 학습        | SR 복습         |
| --------- | ------------------ | --------------- |
| 단어 구성 | 새 단어만          | 복습 단어만     |
| 단어 수   | 일일 목표량 (25개) | 복습 대기 전체  |
| 접근 방법 | "오늘의 학습 시작" | "복습하기" 버튼 |
| 목적      | 새로운 단어 습득   | 기존 단어 복습  |

## 효과적인 학습 방법

### 1. 매일 꾸준히 학습하기

- **권장 학습량**: 하루 25개 (약 60일에 1,500개 1회독)
- **스트릭 유지**: 하루라도 건너뛰면 스트릭이 리셋됩니다
- **최적 시간**: 아침 또는 자기 전 10-15분

### 2. 3단계 학습 사이클 활용하기

```
[1단계] 첫 학습
  └─ 카드를 보며 단어와 뜻을 눈에 익힘
  └─ 부담 없이 "다음 단어"로 진행

[2단계] 복습 퀴즈
  └─ "몰라요/알아요"로 자가 테스트
  └─ 모르는 단어 파악

[3단계] 틀린 단어 반복
  └─ 모두 맞출 때까지 반복
  └─ 완벽히 암기 후 종료
```

### 3. 퀴즈 모드로 실전 연습

- **빈칸 채우기**: 문맥에서 단어 사용법 학습
- **객관식**: 빠른 단어-뜻 매칭 연습
- 학습 후 바로 퀴즈를 풀면 기억 정착에 효과적

### 4. SR 복습 우선 처리하기

- 홈 화면에 "복습할 단어가 있어요" 알림 확인
- **"복습하기" 버튼**으로 복습 단어만 먼저 처리
- 복습 완료 후 "오늘의 학습 시작"으로 새 단어 학습
- 복습을 미루면 단어가 쌓이므로 당일 처리 권장

**권장 학습 순서:**

```
1. SR 복습 (복습하기 버튼) - 복습 대기 단어 처리
2. 오늘의 학습 - 새 단어 학습
3. 퀴즈 모드 - 실전 테스트
```

### 5. 북마크 활용하기

- 헷갈리는 단어는 북마크 추가
- 단어장에서 북마크 필터로 모아보기
- 시험 직전 북마크 단어 집중 복습

### 6. 발음과 함께 학습하기

- 자동 발음 기능 활성화 권장
- 소리와 함께 학습하면 기억력 향상
- GRE Reading에서도 발음을 알면 독해 속도 향상

## 학습 팁

1. **완벽주의 금지**: 첫 학습에서 모든 단어를 외우려 하지 마세요. 간격 반복이 자동으로 복습을 잡아줍니다.

2. **예문 활용**: 단어만 외우지 말고 예문도 함께 읽으세요. 문맥에서 단어 사용법을 익히면 GRE 지문에서도 잘 보입니다.

3. **아는 단어도 학습**: 이미 아는 단어라도 "알아요"를 눌러 진행하세요. 마스터 상태로 빠르게 이동합니다.

4. **학습 시간 고정**: 매일 같은 시간에 학습하면 습관이 형성되어 지속하기 쉽습니다.

5. **시험 2주 전**: 북마크한 단어와 "학습 중" 상태 단어 집중 복습
