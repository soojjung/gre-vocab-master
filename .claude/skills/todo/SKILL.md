`.ai/TODO.md` 에 백로그 아이템을 빠르게 추가합니다. 카테고리는 텍스트 키워드로 자동 판정하고, 애매하면 사용자에게 묻습니다. 자동 커밋은 하지 않습니다.

## 사용 패턴

### 텍스트 있는 호출
사용자: `/todo 아이폰 미니에서 스크롤 안 생기게 정리`
→ UI/UX 카테고리로 자동 분류 후 `- [ ] 아이폰 미니에서 스크롤 안 생기게 정리` 추가.

### 텍스트 없는 호출
사용자: `/todo`
→ "어떤 항목을 추가할까요?" 물어보고 답에 따라 진행. 현재 목록 짧게 보여줘도 OK.

## 작업 흐름

1. **사용자 입력 텍스트 파싱** — 슬래시 명령 뒤 텍스트가 그대로 아이템 본문.

2. **카테고리 자동 판정** (키워드 기반):

   | 카테고리 | 키워드 예시 |
   |---|---|
   | 학습 기능 | 학습, 플래시카드, 복습, SR, 퀴즈, 스트릭, 알림, 리마인더 |
   | 단어 데이터 | 단어, 뜻, 정의, 예문, meaning, PDF, 데이터 |
   | UI / UX | UI, 디자인, 레이아웃, 색, 폰트, 스크롤, 짤, 이모지, 애니메이션, 접근성 |
   | 국제화 | i18n, 번역, 다국어, locale, 한국어, 영어, 일본어 |
   | iOS / 배포 | iOS, App Store, Xcode, 빌드, PWA, manifest, Info.plist |
   | 운영 / 관측 | Sentry, 모니터링, 로그, 알람, 운영, 성능, 분석 |
   | 개발자 경험 | 테스트, vitest, CI, 스크립트, 슬래시, 자동화, 린트, prettier |

   - 두 카테고리에 걸치면 더 가까운 쪽 하나 선택.
   - 어느 카테고리에도 안 맞으면 **사용자에게 한 번만** 물어보고 결정.

3. **한 줄 룰 점검**:
   - 텍스트가 두 줄 이상이거나, 본문에 구체적인 구현/디자인 결정이 들어 있으면 (= 이미 작업 거리)
   - → 사용자에게 알리고 "별도 트랙 문서 (예: `.ai/<topic>.md`) 로 옮길까요?" 제안.
   - 사용자가 그래도 TODO 에 두라고 하면 한 줄로 축약해서 추가.

4. **`.ai/TODO.md` 파싱 + 삽입**:
   - 파일은 단일 표(`| 카테고리 | 항목 |`) 형식. 같은 카테고리의 마지막 행 바로 아래에 `| {카테고리} | {본문} |` 한 줄 추가 (그룹 유지).
   - 새 카테고리면 표 마지막 행 아래에 추가하고 사용자에게 알림.
   - 중복 체크 — 거의 동일한 항목이 이미 있으면 사용자에게 알리고 추가 여부 묻기.

5. **삽입 후 보고**:
   - 어느 카테고리에 어떻게 추가했는지 한 줄 보고.
   - 절대 자동 커밋 X. "검토 후 직접 commit" 안내 (필요 시).

## 주의사항

- `.ai/TODO.md` 의 표 구조와 룰 ("한 줄로 못 쓰겠으면 별도 트랙으로") 을 임의로 바꾸지 말 것.
- 기존 행 순서 / 형식 (`| 카테고리 | 본문 |`) 유지. 컬럼 추가(우선순위, 상태, 담당) 금지 — 파일 룰 위배.
- 작성 후 자동 커밋 금지 (`feedback_commit_only_when_explicitly_asked` 메모리 참조).
- 완료 처리는 이 스킬 범위 밖. 완료된 항목은 행을 삭제하고 git log (커밋 메시지) 로 흔적을 남기는 게 기본. 운영 이슈에서 비롯된 항목일 때만 `.ai/OPERATIONS_LOG.md` 에도 별도 기록.
