### 1. Custom Hook을 통한 로직 분리

컴포넌트에서 복잡한 상태 관리 로직을 커스텀 훅으로 추출하여 관심사를 분리하는 패턴.

**장점:**

- 컴포넌트는 UI 렌더링에만 집중
- 로직 재사용 가능
- 테스트 용이성 향상
- 코드 가독성 개선

**예시:**

```typescript
// Before: 411줄의 StudyPage.tsx
// After: 173줄의 StudyPage.tsx + useStudySession.ts

// useStudySession.ts
export function useStudySession(isReviewOnlyMode: boolean) {
  const [isFlipped, setIsFlipped] = useState(false);
  const [sessionComplete, setSessionComplete] = useState(false);
  // ... 모든 상태와 로직

  return {
    isFlipped,
    sessionComplete,
    handleFlip,
    handleNext,
    // ... 필요한 값들만 노출
  };
}

// StudyPage.tsx
export function StudyPage() {
  const { isFlipped, handleFlip, ... } = useStudySession(isReviewOnlyMode);
  // UI 렌더링만 담당
}
```

### 2. 컴포넌트 추출 (Component Extraction)

중복되는 UI 코드를 재사용 가능한 컴포넌트로 분리하는 리팩토링 기법.

**Before (4번 중복):**

```tsx
<div className="flex items-center justify-end gap-2 mt-6">
  <span className="text-sm text-gray-600">자동 발음</span>
  <button onClick={toggleAutoSpeak} className={...}>
    <div className={...} />
  </button>
</div>
```

**After:**

```tsx
// AutoSpeakToggle.tsx
interface AutoSpeakToggleProps {
  enabled: boolean;
  onToggle: () => void;
}

export function AutoSpeakToggle({ enabled, onToggle }: AutoSpeakToggleProps) {
  return (
    <div className="flex items-center justify-end gap-2 mt-6">
      <span className="text-sm text-gray-600">자동 발음</span>
      <button onClick={onToggle} className={...}>
        <div className={...} />
      </button>
    </div>
  );
}

// 사용
<AutoSpeakToggle enabled={userData.autoSpeak} onToggle={toggleAutoSpeak} />
```

### 3. 학습 모드 상태 패턴 (State Machine Pattern)

여러 학습 모드(기본/퀴즈/복습/SR)를 상태 플래그로 관리하는 패턴.

| 모드      | 상태 플래그        | 대상 단어                 | 버튼          |
| --------- | ------------------ | ------------------------- | ------------- |
| 기본 학습 | 기본 상태          | `studyWords`              | 다음 단어     |
| 퀴즈 모드 | `quizMode: true`   | `studyWords`              | 알아요/몰라요 |
| 복습 모드 | `reviewMode: true` | `reviewWords` (틀린 단어) | 알아요/몰라요 |
| SR 복습   | `isReviewOnlyMode` | `srReviewWords`           | 다음 단어     |

```typescript
// 조건부 렌더링
if (reviewMode && reviewWords.length > 0) {
  return <복습 UI />;
}
if (quizMode && studyWords.length > 0) {
  return <퀴즈 UI />;
}
return <기본 학습 UI />;
```

### 4. useCallback과 useMemo 활용

React에서 불필요한 재렌더링을 방지하기 위한 메모이제이션 훅.

**useMemo** - 계산된 값 캐싱:

```typescript
// 복습할 단어 목록 (의존성 변경 시에만 재계산)
const reviewWords = useMemo(() => {
  return sessionStats.wrongWordIds.map((id) => words.find((w) => w.id === id)).filter((w) => w !== undefined);
}, [sessionStats.wrongWordIds]);
```

**useCallback** - 함수 캐싱:

```typescript
// 핸들러 함수 (의존성 변경 시에만 재생성)
const handleFlip = useCallback(() => setIsFlipped(true), []);

const handleNext = useCallback(() => {
  if (!currentWord) return;
  recordAnswer(String(currentWord.id), true);
  // ...
}, [currentWord, currentIndex, studyWords.length, recordAnswer]);
```

### 5. Barrel Export 패턴

관련 컴포넌트들을 index.ts를 통해 한 곳에서 export하는 패턴.

```typescript
// src/components/study/index.ts
export { FlashCard } from "./FlashCard";
export { StudyComplete } from "./StudyComplete";
export { StudyHeader } from "./StudyHeader";
export { AnswerButtons } from "./AnswerButtons";
export { AutoSpeakToggle } from "./AutoSpeakToggle";

// 사용 시 깔끔한 import
import { FlashCard, StudyComplete, StudyHeader, AnswerButtons, AutoSpeakToggle } from "@/components/study";
```
