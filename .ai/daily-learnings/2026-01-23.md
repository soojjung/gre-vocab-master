## 기술 개념

### 1. TypeScript 타입 안전 데이터 구조

GRE 단어장에서 사용하는 Word 타입 구조:

```typescript
import type { Word } from "@/types";

interface Word {
  id: number;
  word: string;
  meaning: string;      // 한국어 뜻
  example: string;      // 영어 예문
  exampleKo: string;    // 한국어 예문 번역
  difficulty: number;   // 난이도 (1-3)
}
```

**핵심 포인트:**
- `type` import를 사용하여 타입만 가져오기 (번들 크기 최적화)
- 일관된 데이터 구조로 타입 안전성 확보

### 2. 데이터 파일 분할 패턴

대량의 데이터를 여러 파일로 분할하는 패턴:

```typescript
// words-1.ts ~ words-9.ts로 분할
// 각 파일당 약 200개 단어 (마지막 파일 제외)

// index.ts에서 통합
import { words1 } from "./words-1";
import { words2 } from "./words-2";
// ...
export const allWords = [...words1, ...words2, ...];
```

**장점:**
- 파일별 로딩 가능 (lazy loading)
- 코드 리뷰 및 유지보수 용이
- 린터/포매터 처리 시간 단축

### 3. 다국어 콘텐츠 관리

한 객체 내에서 다국어 필드를 관리하는 방식:

```typescript
{
  word: "abhorrent",           // 원어
  meaning: "혐오스러운",        // 번역된 뜻
  example: "The behavior...",  // 원어 예문
  exampleKo: "그 행동은..."    // 번역된 예문
}
```

**대안 패턴:**
- i18n 라이브러리 사용 (react-i18next 등)
- 별도 번역 파일 분리 (en.json, ko.json)
