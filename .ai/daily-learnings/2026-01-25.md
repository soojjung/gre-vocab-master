# 2026-01-25 학습 정리

## 오늘 배운 개념

### 1. **Dynamic Viewport Height (dvh)**

모바일 브라우저에서 주소창을 고려한 뷰포트 높이 단위

- `100vh`: 브라우저 주소창 포함한 전체 높이 (모바일에서 콘텐츠가 잘릴 수 있음)
- `100dvh`: 실제 보이는 화면 높이 (주소창 제외)

```css
/* 기존 - 모바일에서 버튼이 화면 밖으로 */
.container {
  min-height: 100vh;
}

/* 개선 - 실제 보이는 화면에 맞춤 */
.container {
  min-height: 100dvh;
}
```

Tailwind CSS 4에서는 `min-h-dvh` 클래스로 사용 가능

### 2. **Fixed Header with Safe Area**

iOS PWA에서 상단 노치/다이나믹 아일랜드 영역을 고려한 고정 헤더 구현

```tsx
// 헤더 컴포넌트
<div className="fixed top-0 left-0 right-0 z-10
  pt-[calc(1rem+env(safe-area-inset-top))]">
  {/* 헤더 내용 */}
</div>

// 콘텐츠 영역 - 헤더 높이만큼 패딩 추가
<div className="pt-[calc(5rem+env(safe-area-inset-top))]">
  {/* 페이지 콘텐츠 */}
</div>
```

`env(safe-area-inset-*)`: CSS 환경 변수로 디바이스 안전 영역 값 제공

### 3. **React Hooks 규칙 (Rules of Hooks)**

React Hooks는 반드시 컴포넌트 최상위에서 호출해야 함

```tsx
// 잘못된 예 - early return 후에 Hook 호출
function Component() {
  if (loading) return <Loading />;

  const callback = useCallback(() => {}, []); // Error!
  return <div />;
}

// 올바른 예 - 모든 Hook을 early return 전에 선언
function Component() {
  const callback = useCallback(() => {}, []);

  if (loading) return <Loading />;
  return <div />;
}
```

### 4. **useRef와 렌더링**

렌더링 중에 ref.current를 직접 수정하면 안 됨

```tsx
// 잘못된 예 - 렌더링 중 ref 수정
const ref = useRef(value);
ref.current = value; // Error!

// 올바른 예 - useEffect로 ref 동기화
const ref = useRef(value);
useEffect(() => {
  ref.current = value;
}, [value]);
```

ref는 렌더링에 영향을 주지 않는 값을 저장할 때 사용 (이벤트 핸들러, setTimeout 콜백에서 최신 값 참조)

### Q1. 모바일 브라우저에서 버튼이 화면 아래로 잘리는 문제를 해결하기 위해 사용해야 하는 CSS 단위는?

- A) `vh`
- B) `dvh`
- C) `svh`
- D) `lvh`

<summary>정답 보기</summary>

**B) `dvh` (Dynamic Viewport Height)**

`dvh`는 모바일 브라우저의 주소창 표시 여부에 따라 동적으로 변하는 뷰포트 높이를 제공합니다.

</details>

### Q2. 다음 코드의 문제점은 무엇인가요?

```tsx
function Quiz() {
  if (loading) return <Loading />;

  const [count, setCount] = useState(0);
  return <div>{count}</div>;
}
```

- A) useState는 함수 컴포넌트에서 사용할 수 없다
- B) Hook이 조건부 return 이후에 호출되어 규칙 위반
- C) setCount가 사용되지 않았다
- D) 문제 없음

<details>
<summary>정답 보기</summary>

**B) Hook이 조건부 return 이후에 호출되어 규칙 위반**

React Hooks는 항상 동일한 순서로 호출되어야 합니다. early return 전에 모든 Hook을 선언해야 합니다.

</details>

### Q3. iOS PWA에서 노치 영역을 고려하기 위해 사용하는 CSS 환경 변수는?

- A) `var(--safe-area-top)`
- B) `env(safe-area-inset-top)`
- C) `calc(safe-area-top)`
- D) `inset(safe-area-top)`

<summary>정답 보기</summary>

**B) `env(safe-area-inset-top)`**

`env()` 함수를 사용하여 디바이스의 안전 영역 값에 접근할 수 있습니다.

</details>
