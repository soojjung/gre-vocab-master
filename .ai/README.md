# 단어의 신 GRE - PWA 플래시카드 앱 개발

(부제: GRE Vocab Master)

## 📋 프로젝트 개요

- **앱 이름**: 단어의 신 GRE
- **목적**: GRE 시험 대비 1500 단어 암기 플래시카드 앱
- **플랫폼**: PWA (Progressive Web App)
- **디자인**: 미니멀 (흰색/검정 위주, 깔끔한 UI)

## 🛠 기술 스택

- React + TypeScript
- Tailwind CSS
- LocalStorage (진도/설정 저장)
- PWA (offline support, 홈 화면 추가 가능)

## 📱 화면 구성

### 1. 홈 화면

- D-day 표시 (목표 시험일까지 남은 일수)
- D-day 기본값: 오늘로부터 60일 후 (설정에서 변경 가능)
- 전체 진도율 프로그레스 바 (학습 완료 단어 / 1500)
- 오늘 학습 현황 (오늘 학습한 단어 / 일일 목표 25개)
- 복습 대기 단어 수
- 버튼: [오늘의 학습 시작], [퀴즈 모드], [단어장]

### 2. 학습 모드 (플래시카드)

- 카드 앞면: 영어 단어만 표시
- 카드 탭/클릭 시: 뜻(한글) + 예문 공개
- 하단 버튼: [몰라요 ❌] [알아요 ✓]
- Spaced Repetition 적용:
  - "몰라요" → 복습 간격 짧게 (1일 후)
  - "알아요" → 복습 간격 늘림 (2일 → 4일 → 7일 → 14일)
- 상단에 진행률 표시 (12/25)

### 3. 퀴즈 모드

두 가지 퀴즈 타입 선택 화면:

#### 3-1. 빈칸 채우기

- 예문에서 단어 부분을 **\_\_** 로 표시
- 4개 보기 중 정답 선택 (영어 단어)
- 정답/오답 즉시 피드백

#### 3-2. 객관식

- 한글 뜻 제시
- 4개 영어 단어 보기 중 정답 선택
- 정답/오답 즉시 피드백

공통:

- 문제 수 선택: 10 / 20 / 50문제
- 결과 화면: 점수, 틀린 단어 목록

### 4. 단어장

- 검색 기능 (영어/한글)
- 필터 탭: [전체] [학습중] [암기완료] [북마크]
- 각 단어 카드: 단어, 뜻, 암기율(%), 북마크 토글
- 단어 클릭 시 상세보기 (뜻, 예문, 학습 이력)

### 5. 통계

- 전체 진도율 (프로그레스 바 + 숫자)
- 이번 주 일별 학습량 바 차트
- 연속 학습일 (streak)

### 6. 설정

- D-day 날짜 변경 (날짜 선택기)
- 일일 목표 단어 수 변경 (기본 25개)
- 데이터 초기화 버튼

## 🎨 디자인 가이드

- 배경: #FFFFFF (라이트), #000000 (다크모드 - 추후)
- 주요 텍스트: #1a1a1a
- 보조 텍스트: #666666
- 액센트 컬러: #000000 (버튼, 강조)
- 성공: #22c55e (초록)
- 실패: #ef4444 (빨강)
- 카드: 흰 배경 + 미세한 그림자
- 폰트: 시스템 폰트 (Pretendard 또는 -apple-system)
- 버튼: 둥근 모서리 (rounded-xl), 충분한 패딩

## 🚀 개발 순서
